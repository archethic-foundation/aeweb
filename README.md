# aeWeb/aeHosting

### Main features
- Deploy and update static sites on the Archethic Blockchain
- SSL Certificate management

### Security
- Security access with your Archethic Wallet >= 4.14.1

### Pre-requisites
- Flutter 3.27+
- Dart 3.6+
